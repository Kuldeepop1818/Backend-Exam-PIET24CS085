A REST API built with Node.js, Express, MongoDB and Mongoose to create, read, update and delete library books.

## Features
- Create a book (`POST /books`)
- List all books (`GET /books`)
- Get one book by ID (`GET /books/:id`)
- Update a book (`PUT /books/:id`)
- Delete a book (`DELETE /books/:id`)
- Mongoose schema validation
- Request logger middleware
- Central error-handling middleware
- MongoDB connection string loaded from `.env`

## Requirements
- Node.js and npm
- MongoDB Community Server running locally, or a MongoDB Atlas connection
- VS Code (recommended)
- Postman or Thunder Client
- MongoDB Compass (for viewing stored records)

## Setup
1. Open this project folder in VS Code.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to a new file named `.env`.
4. In `.env`, set your MongoDB connection string:
   ```env
   MONGO_URI=mongodb://127.0.0.1:27017/libraryDB
   PORT=3000
   ```
   If using MongoDB Atlas, use your own Atlas connection string instead.
5. Make sure MongoDB is running.
6. Start the API:
   ```bash
   npm start
   ```

Expected terminal messages:
```text
MongoDB connected successfully
Server running on port 3000
```

## API endpoints

| Method | Endpoint | Description | Success status |
|---|---|---|---|
| POST | `/books` | Create a book | 201 |
| GET | `/books` | Get all books | 200 |
| GET | `/books/:id` | Get a book by ID | 200 |
| PUT | `/books/:id` | Update a book | 200 |
| DELETE | `/books/:id` | Delete a book | 200 |

Invalid input returns `400`. A valid ID for a book that does not exist returns `404`.

## Example request: create a book
Choose `POST` and enter `http://localhost:3000/books` in Postman or Thunder Client. Select **Body → JSON** and send:

```json
{
  "title": "Python Programming",
  "author": "John Smith",
  "price": 450,
  "category": "Programming",
  "isAvailable": true
}
```

Example update request (`PUT /books/BOOK_ID`):
```json
{
  "price": 500,
  "isAvailable": false
}
```

Replace `BOOK_ID` with the `_id` returned by the POST request.

## MongoDB Compass
